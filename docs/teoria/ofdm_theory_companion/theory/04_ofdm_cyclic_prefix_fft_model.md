# 04 — OFDM, cyclic prefix and FFT-domain subchannels

OFDM groups `N=32` QAM symbols into a frequency-domain vector

```math
\\mathbf{X} = [X[0],X[1],\\ldots,X[31]]^T.
```

The time-domain OFDM block is generated by the inverse DFT:

```math
x[n] = \\frac{1}{N}\\sum_{k=0}^{N-1}X[k]e^{j2\\pi kn/N}.
```

In NumPy, this is `np.fft.ifft(X, N)`.

## Cyclic prefix

The cyclic prefix copies the last `N_CP` samples of the OFDM block and places them before the block:

```text
[x[N-N_CP], ..., x[N-1], x[0], ..., x[N-1]]
```

The minimum prefix length that avoids inter-block interference for an FIR channel of length `L_h` is

```math
N_{CP} \\geq L_h-1.
```

For this project:

```math
N_{CP,min}=6-1=5.
```

## Why the cyclic prefix works

Without the cyclic prefix, the channel performs linear convolution and the block edges do not align with a DFT model. With a long enough cyclic prefix, after removing the prefix at the receiver, the useful part of the received block is equivalent to circular convolution:

```math
\\mathbf{y} = \\mathbf{h} \\circledast \\mathbf{x} + \\mathbf{w}.
```

The DFT diagonalizes circular convolution:

```math
Y[k] = H[k]X[k] + V[k].
```

This is the central OFDM result. A frequency-selective channel becomes 32 parallel scalar subchannels.

## Implementation sequence

1. Map bits to 16-QAM symbols.
2. Reshape into OFDM blocks with 32 carriers.
3. Apply IFFT.
4. Append cyclic prefix of length 5.
5. Convolve with the FIR channel.
6. Add AWGN.
7. Remove cyclic prefix.
8. Apply FFT.
9. Equalize each subcarrier.
10. Decide symbols and compute SER.
