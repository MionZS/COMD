# Pacote de teoria expandida — TC2 Comunicação Digital

Este pacote contém quatro arquivos Markdown expandidos para estudar e defender o artigo do Trabalho Computacional 2.

Arquivos:

1. `teoria.md` — cadeia de transmissão em banda passante, bits, Gray coding, constelações, pulsos e modulação.
2. `teoria2.md` — canal AWGN, variância, demodulação coerente, filtro casado e amostragem.
3. `teoria3.md` — decisão ML, geometria da constelação, função Q e BER teórica.
4. `teoria4.md` — Monte Carlo, convergência estatística, leitura das curvas e defesa dos resultados.

A expansão foi feita com base em:

- enunciado do TC2;
- notebooks Marimo do projeto;
- código do colega;
- referências MathWorks sobre BER;
- referências clássicas de comunicações digitais, como Proakis/Salehi e Lathi/Ding;
- literatura técnica sobre filtro RRC, critério de Nyquist e filtro casado.
